# 📚 BCA Saurashtra Papers CDN
Welcome to the official Content Delivery Network (CDN) repository for the **BCA Saurashtra Question Papers** portal.
This repository serves as the public, high-speed storage bucket for hosting previous year examination PDF papers for Saurashtra University BCA students. By hosting files here, we leverage GitHub's global edge network to ensure zero downtime and lightning-fast downloads for students.
## 🚀 How it works
This repository contains **only** static PDF files. Our private web frontend fetches these files dynamically using GitHub's raw URLs. 
Example raw link structure:
`https://.....pdf`
## 📂 Structure
- All PDF files are uploaded directly to the root directory.
- Files are named clearly by subject and year (e.g., `Java_2025.pdf`) for easy reference.
## 🔒 Usage & Copyright
These papers are collected and archived for **educational and academic purposes only** to assist BCA students in their exam preparation. They belong to Saurashtra University.
